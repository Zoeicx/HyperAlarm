HyperAlarm — модуль Xposed, **единственная область действия которого — «Часы» Xiaomi**. Он превращает будильники в триггеры для shell-скриптов.

## Целевое приложение

Проверено только на версиях ниже. В остальных случаях проверяйте сами, присылайте APK для адаптации либо обновитесь/откатитесь до них:

- Часы Xiaomi `com.android.deskclock`
- Версия `18.28.0`, код версии `1306002800`

## Установка

1. Нужны root (KernelSU / Magisk) и LSPosed (Xposed API 101 или новее).
2. Установите модуль и включите HyperAlarm в LSPosed.
3. В области действия отметьте только `com.android.deskclock`. Никаких других пакетов.
4. Принудительно остановите «Часы» и дайте процессу запуститься заново — иначе модуль не заработает.

## Использование

- Новая задача: `+` в правой части верхней панели действий.
- Метка будильника — это имя скрипта, оно должно заканчиваться на `.sh`:
  - `alert.sh`: срабатывает молча — без звонка и без экрана будильника
  - `@alert.sh`: запускает скрипт и оставляет экран будильника с мелодией
- В списке `@` скрывается; переключатель «Мелодия» переносит задачу между режимами.
- «Выполнить сейчас» позволяет проверить скрипт, не дожидаясь времени.
- Сменные задачи срабатывают по сменам, которые вычисляются из даты начала и цикла.

## Правила для скриптов

Скрипты лежат в `/data/adb/alarm_shell/scripts/`, имя в метке должно совпадать с именем файла.

```text
/data/adb/alarm_shell/scripts/      # каталог скриптов
/data/adb/alarm_shell/password      # пароль блокировки экрана
/data/adb/alarm_shell/unlock_phone  # скрипт разблокировки по умолчанию
```

- Перевод строки — только LF. Файл с CRLF из Windows просто не запустится.
- Скрипт работает от root в основном пространстве имён системы, поэтому видит каталоги данных других приложений.
- Каждый запуск оставляет лог: его видно на странице «Логи скриптов» в приложении, а копия лежит в
  `/sdcard/Android/data/com.hyperalarm/files/script_logs/<имя скрипта>/`.
- Перед тихой задачей модуль разблокирует экран вашим паролем блокировки, если он задан.

## Настройки

- **Часы показывают только будильники**: в списке «Часов» остаются настоящие будильники, задачи-скрипты не показываются.
- **Скрывать звонящие задачи**: прячет и задачи с включённой мелодией.
- Уровень логов / Логи приложения / Логи скриптов: при разборе проблемы сначала поднимите уровень.
- **Пароль блокировки экрана**: нужен для разблокировки перед тихой задачей; пустое поле — не менять.
- Мастер перезапуска, копирование каталога скриптов, резервная копия и восстановление настроек.

## Известные ограничения

- Проверено только на Android 16 / HyperOS 3 / Часах 18.28.0; остальные сочетания — на ваш риск.
- Сменный режим опирается на внутреннюю реализацию «Часов», после обновления часов его нужно проверять заново.
- Без root модуль не работает; страница настроек об этом сообщает.
- Логи скриптов копируются во внешнее хранилище и доступны root и adb shell. Не выводите секреты в лог.

## Частые вопросы

- **Задача добавлена, но часы молчат**: проверьте, что модуль включён в LSPosed, область действия — только «Часы», и процесс часов перезапускался.
- **Задачи нет в списке часов**: работает «Часы показывают только будильники», отключите её.
- **Время пришло, а ничего не выполнилось**: смотрите логи скриптов в приложении — отсутствующий скрипт или опечатка в метке там видны.
