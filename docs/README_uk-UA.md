HyperAlarm — модуль Xposed, **єдина область дії якого — «Годинник» Xiaomi**. Він перетворює будильники на тригери для shell-скриптів.

## Цільовий застосунок

Перевірено лише на наведених версіях. В інших випадках перевіряйте самі, надсилайте APK для адаптації або оновіться/відкатіться до них:

- Годинник Xiaomi `com.android.deskclock`
- Версія `18.28.0`, код версії `1306002800`

## Встановлення

1. Потрібні root (KernelSU / Magisk) і LSPosed (Xposed API 101 або новіший).
2. Встановіть модуль і ввімкніть HyperAlarm у LSPosed.
3. В області дії позначте лише `com.android.deskclock`. Жодних інших пакетів.
4. Примусово зупиніть «Годинник» і дайте процесу запуститися заново — інакше модуль не працюватиме.

## Використання

- Нова задача: `+` у правій частині верхньої панелі дій.
- Мітка будильника — це ім'я скрипта, воно має закінчуватися на `.sh`:
  - `alert.sh`: спрацьовує тихо — без дзвінка й без екрана будильника
  - `@alert.sh`: запускає скрипт і лишає екран будильника з мелодією
- У списку `@` ховається; перемикач «Мелодія» переносить задачу між режимами.
- «Виконати зараз» дозволяє перевірити скрипт, не чекаючи часу.
- Змінні задачі спрацьовують за змінами, які обчислюються з дати початку й циклу.

## Правила для скриптів

Скрипти лежать у `/data/adb/alarm_shell/scripts/`, ім'я в мітці має збігатися з іменем файла.

```text
/data/adb/alarm_shell/scripts/      # тека скриптів
/data/adb/alarm_shell/password      # пароль блокування екрана
/data/adb/alarm_shell/unlock_phone  # типовий скрипт розблокування
```

- Перехід рядка — лише LF. Файл із CRLF з Windows просто не запуститься.
- Скрипт працює від root у головному просторі назв системи, тому бачить теки даних інших застосунків.
- Кожен запуск лишає лог: його видно на сторінці «Логи скриптів» у застосунку, а копія лежить у
  `/sdcard/Android/data/io.github.zoeicx.hyperalarm/files/script_logs/<ім'я скрипта>/`.
- Перед тихою задачею модуль розблокує екран вашим паролем блокування, якщо він заданий.

## Налаштування

- **Годинник показує лише будильники**: у списку «Годинника» лишаються справжні будильники, задачі-скрипти не показуються.
- **Ховати задачі зі дзвінком**: приховує й задачі з увімкненою мелодією.
- Рівень логів / Логи застосунку / Логи скриптів: під час розбору проблеми спершу підніміть рівень.
- **Пароль блокування екрана**: потрібен для розблокування перед тихою задачею; порожнє поле — не змінювати.
- Майстер перезапуску, копіювання теки скриптів, резервна копія та відновлення налаштувань.

## Відомі обмеження

- Перевірено лише на Android 16 / HyperOS 3 / Годиннику 18.28.0; інші поєднання — на ваш ризик.
- Змінний режим спирається на внутрішню реалізацію «Годинника», після оновлення годинника його треба перевіряти заново.
- Без root модуль не працює; сторінка налаштувань про це повідомляє.
- Логи скриптів копіюються в зовнішнє сховище й доступні root і adb shell. Не виводьте секрети в лог.

## Часті питання

- **Задачу додано, але годинник мовчить**: перевірте, що модуль увімкнено в LSPosed, область дії — лише «Годинник», і процес годинника перезапускався.
- **Задачі немає в списку годинника**: працює «Годинник показує лише будильники», вимкніть її.
- **Час настав, а нічого не виконалося**: дивіться логи скриптів у застосунку — відсутній скрипт або друкарська помилка в мітці там видні.
