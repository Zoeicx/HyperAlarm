本プライバシーポリシーは、HyperAlarm（以下「本モジュール」）がユーザーの情報をどのように扱うかを説明します。結論から言うと、本モジュールは個人データを収集せず、アップロードもしません。ログと設定はすべてこの端末に残ります。以下に項目ごとに説明します。

## 0. バージョンと発効日

- 0.1. ポリシーバージョン：1.0
- 0.2. 発効日：2026 年 11 月 15 日
- 0.3. 本ポリシーは各ビルドに同梱されて配布されます。

## 1. 端末内に保存される情報

- 1.1. スクリプトログ：各スクリプト実行の開始時刻、終了コード、標準出力、標準エラー。本モジュールのデータベースと外部ストレージディレクトリに保存されます。
- 1.2. アプリログ：問題の調査に使用する、本モジュール自身の動作ログ。
- 1.3. クラッシュ記録：セーフモードで使用する例外の概要。本モジュールのプライベートディレクトリに保存されます。
- 1.4. 設定：言語、ログレベル、リストフィルターのオン／オフなど。本モジュールの設定ファイルに保存されます。
- 1.5. ロック画面のパスワード：設定でユーザー自身が入力した場合にのみファイルに書き込まれ、パーミッションは 600、root と本モジュールのみが読み取れます。サイレントタスクの実行前に画面のロックを解除するために使用します。
- 1.6. 上記はいずれも、ユーザー自身がエクスポート、共有、または issue に投稿しない限り、端末外に出ることはありません。

## 2. 収集しない情報

- 2.1. 端末識別子（IMEI、Android ID、シリアル番号など）は収集しません。
- 2.2. 位置情報は収集しません。
- 2.3. 連絡先、SMS、通話履歴は収集しません。
- 2.4. スクリプトの内容は収集しません。
- 2.5. 本モジュールには、分析、クラッシュレポート、広告の SDK は含まれません。

## 3. ネットワークに関わる 2 か所

- 3.1. 概要ページは GitHub の公開インターフェースを呼び出し、作者のアバターと貢献者リストを取得します。リクエストは api.github.com と avatars.githubusercontent.com にのみ送信され、GitHub が要求する標準の User-Agent を含みますが、端末またはユーザーを識別する情報は含みません。そのため、GitHub はユーザーの IP アドレスを認識します。
- 3.2. 初回セットアップウィザードと設定ページは、文書をバージョンから独立して更新できるよう、GitHub から利用規約と本ポリシーの本文を取得します。これらのリクエストも標準ヘッダーのみを含みます。取得に失敗した場合は、インストールパッケージ内のコピーを表示するか、失敗の通知を表示します。
- 3.3. 上記以外に、本モジュールはネットワークリクエストを行いません。

## 4. 第三者との共有

- 4.1. 当方は何も収集していないため、第三者と情報を共有することはありません。
- 4.2. 上記の GitHub へのリクエストは、ユーザーと GitHub の直接のやり取りであり、GitHub 自身のプライバシーポリシーに従います。
- 4.3. ユーザーが自らログをエクスポートして共有する場合、受領者はユーザーが選択するものであり、当方による共有には該当しません。

## 5. 保存と削除

- 5.1. ログは固定の上限に従って自動的に整理され、上限を超えると最も古い記録から削除されます。
- 5.2. アプリ内でログを消去するか、本モジュールのデータを直接削除できます。
- 5.3. 本モジュールをアンインストールすると、そのプライベートディレクトリ内のすべてのデータも削除されます。
- 5.4. 外部ストレージにミラーされたログは、アンインストール前にユーザー自身で削除する必要があります。

## 6. ユーザーの権利

- 6.1. 本モジュールが保存するすべての情報を、いつでも閲覧、エクスポート、消去できます。
- 6.2. いかなる権限も拒否できます。対応する機能は利用できなくなります。
- 6.3. 設定でロック画面のパスワードを消去でき、ファイルの内容は空になります。

## 7. 未成年者

- 7.1. 本モジュールは、一定のシステム知識を持つユーザーを対象としています。未成年者は保護者の指導のもとで使用してください。
- 7.2. root とスクリプトの実行を伴うため、未成年者による単独での使用は推奨しません。

## 8. ポリシーの変更

- 8.1. 本ポリシーはリリースに伴い改訂されることがあります。改訂版は新しいビルドに同梱され、リポジトリで公開されます。
- 8.2. 改訂が新たな情報の取扱いを含む場合、更新ノートに明記します。
