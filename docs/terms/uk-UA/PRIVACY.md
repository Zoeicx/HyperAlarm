Ця політика пояснює, як HyperAlarm (далі — «модуль») обробляє вашу інформацію. Коротко: модуль нічого не збирає й нічого не завантажує. Ваші журнали та налаштування залишаються на цьому пристрої. Докладно нижче.

## 0. Версія та дата набрання чинності

- 0.1. Версія політики: 1.0
- 0.2. Дата набрання чинності: 15 листопада 2026 року
- 0.3. Ця політика постачається разом із кожною збіркою.

## 1. Що зберігається на пристрої

- 1.1. Журнали скриптів: час запуску, код завершення, стандартний вивід і стандартні помилки кожного виконання скрипта. Зберігаються в базі даних модуля та каталозі на зовнішньому сховищі.
- 1.2. Журнали застосунку: власний журнал роботи модуля для діагностики.
- 1.3. Записи про збої: короткі описи винятків для безпечного режиму, зберігаються в приватному каталозі модуля.
- 1.4. Налаштування: мова, рівень журналювання, фільтри списків тощо, зберігаються у файлі налаштувань модуля.
- 1.5. Пароль блокування екрана: записується у файл лише якщо ви самі ввели його в налаштуваннях; права 600, доступний лише root і модулю; використовується для розблокування екрана перед виконанням тихої задачі.
- 1.6. Ніщо з переліченого не залишає пристрій, якщо ви самі не експортуєте, не передасте або не опублікуєте це в issue.

## 2. Що ми не збираємо

- 2.1. Ідентифікатори пристрою (IMEI, Android ID, серійний номер тощо).
- 2.2. Дані про місцеположення.
- 2.3. Контакти, повідомлення та журнал викликів.
- 2.4. Вміст ваших скриптів.
- 2.5. Модуль не містить аналітики, засобів звітування про збої або рекламних SDK.

## 3. Два мережеві запити

- 3.1. Сторінка «Про програму» звертається до публічних інтерфейсів GitHub, щоб отримати аватар автора та список учасників. Запити надсилаються лише на api.github.com і avatars.githubusercontent.com, містять стандартний User-Agent, який вимагає GitHub, і не містять ідентифікаторів пристрою чи користувача. Тому GitHub бачить вашу IP-адресу.
- 3.2. Майстер початкового налаштування та сторінка налаштувань завантажують текст угоди користувача й цієї політики з GitHub, щоб документи можна було оновлювати незалежно від версії. Ці запити також містять лише стандартні заголовки. Якщо завантаження не вдалося, показується копія зі встановленого пакета або повідомлення про помилку.
- 3.3. Крім цього, модуль не робить жодних мережевих запитів.

## 4. Передача третім сторонам

- 4.1. Ми нікому нічого не передаємо, оскільки нічого не збираємо.
- 4.2. Зазначені запити до GitHub є вашою безпосередньою взаємодією з GitHub і регулюються власною політикою конфіденційності GitHub.
- 4.3. Якщо ви самі експортуєте й передаєте журнали, отримувача обираєте ви; це не є розкриттям з нашого боку.

## 5. Зберігання та видалення

- 5.1. Журнали автоматично обрізаються до фіксованої межі: після перевищення видаляються найстаріші записи.
- 5.2. Ви можете очистити журнали в застосунку або безпосередньо видалити дані модуля.
- 5.3. Видалення модуля також видаляє всі дані в його приватних каталогах.
- 5.4. Дзеркальні копії журналів у зовнішньому сховищі потрібно видалити вручну до видалення модуля.

## 6. Ваші права

- 6.1. Ви можете будь-коли переглядати, експортувати та видаляти всі відомості, що зберігає модуль.
- 6.2. Ви можете відмовити в будь-якому дозволі; відповідна функція перестане працювати.
- 6.3. Ви можете очистити пароль блокування екрана в налаштуваннях; вміст файлу буде очищено.
