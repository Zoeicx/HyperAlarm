本隐私政策说明 HyperAlarm（下称「本模块」）如何处理你的信息。结论先说：本模块不收集、不上传任何个人数据，你的日志与设置都留在这台设备上。以下逐项说明。

## 〇、版本与生效日期

- 0.1. 政策版本：1.0
- 0.2. 生效日期：2026 年 11 月 15 日
- 0.3. 本政策随每个构建版本一同发布。

## 一、保存在本机的信息

- 1.1. 脚本日志：每次脚本执行的时间、退出码、标准输出与标准错误。保存在本模块的数据库与外部存储目录下。
- 1.2. 应用日志：模块自身的运行日志，用于排查问题。
- 1.3. 崩溃记录：用于安全模式的异常摘要，保存在本模块私有目录。
- 1.4. 设置项：语言、日志等级、列表过滤开关等，保存在本模块的配置文件。
- 1.5. 锁屏密码：仅当你在设置中主动填写时写入文件，权限为 600，只有 root 与本模块可读；用于静默任务执行前解锁屏幕。
- 1.6. 以上内容都不会离开你的设备，除非你自己导出、分享或提交到 issue。

## 二、我们不收集的信息

- 2.1. 不收集设备标识符（IMEI、Android ID、序列号等）。
- 2.2. 不收集位置信息。
- 2.3. 不收集通讯录、短信、通话记录。
- 2.4. 不收集你的脚本内容。
- 2.5. 本模块不含统计、崩溃上报或广告 SDK。

## 三、涉及网络的两处

- 3.1. 关于页会请求 GitHub 公开接口，读取作者头像与贡献者名单。请求只发往 api.github.com 与 avatars.githubusercontent.com，携带 GitHub 要求的标准 User-Agent，不携带任何设备或用户标识。GitHub 会因此看到你的 IP 地址。
- 3.2. 首次启动向导与设置页会从 GitHub 拉取用户协议与隐私政策的正文，使文本可以独立于版本更新。请求同样只携带标准请求头。若拉取失败，将显示安装包内的副本或给出失败提示。
- 3.3. 除此之外，本模块不发起任何网络请求。

## 四、与第三方共享

- 4.1. 我们不与任何第三方共享你的信息，因为我们根本不收集。
- 4.2. 上述 GitHub 请求属于你直接与 GitHub 交互，受 GitHub 自身隐私政策约束。
- 4.3. 当你主动导出日志并分享时，接收方由你选择，此行不构成我们的共享行为。

## 五、保留与删除

- 5.1. 日志按固定上限自动裁剪，超出后删除最旧的记录。
- 5.2. 你可以在应用内清空日志，或直接删除模块数据。
- 5.3. 卸载本模块会一并删除其私有目录中的全部数据。
- 5.4. 外部存储中的日志镜像需要你在卸载前手动删除。

## 六、你的权利

- 6.1. 你可以随时查看、导出、清空本模块保存的全部信息。
- 6.2. 你可以拒绝任何权限，对应功能将不可用。
- 6.3. 你可以在设置中清除锁屏密码，文件内容会被清空。

## 七、未成年人

- 7.1. 本模块面向具备一定系统知识的用户。未成年人应在监护人指导下使用。
- 7.2. 因为涉及 root 与脚本执行，我们不建议未成年人独立操作。

## 八、政策变更

- 8.1. 本政策可能随版本更新修订，修订后的版本随新构建发布并在仓库中公开。
- 8.2. 若某次修订涉及新的信息处理方式，我们会在更新说明中明确写出。

## 九、联系我们

- 9.1. 隐私相关问题请通过项目仓库的 issue 反馈。
- 9.2. 本模块的源代码公开可审计，你可以自行验证上述说法。
