本隱私權政策說明 HyperAlarm（下稱「本模組」）如何處理你的資訊。先說結論：本模組不收集、不上傳任何個人資料，你的日誌與設定都留在這台裝置上。以下逐項說明。

## 0. 版本與生效日期

- 0.1. 政策版本：1.0
- 0.2. 生效日期：2026 年 11 月 15 日
- 0.3. 本政策隨每個建置版本一同發布。

## 1. 保存在本機的資訊

- 1.1. 腳本日誌：每次腳本執行的時間、結束碼、標準輸出與標準錯誤。保存在本模組的資料庫與外部儲存目錄下。
- 1.2. 應用程式日誌：模組本身的執行日誌，用於排查問題。
- 1.3. 當機記錄：供安全模式使用的例外摘要，保存在本模組的私有目錄。
- 1.4. 設定項目：語言、日誌等級、清單篩選開關等，保存在本模組的設定檔。
- 1.5. 鎖定畫面密碼：僅在你於設定中主動填寫時寫入檔案，權限為 600，只有 root 與本模組可讀；用於靜默任務執行前解鎖畫面。
- 1.6. 以上內容都不會離開你的裝置，除非你自己匯出、分享或提交至問題回報。

## 2. 我們不收集的資訊

- 2.1. 不收集裝置識別碼（IMEI、Android ID、序號等）。
- 2.2. 不收集位置資訊。
- 2.3. 不收集通訊錄、簡訊、通話記錄。
- 2.4. 不收集你的腳本內容。
- 2.5. 本模組不含統計、當機回報或廣告 SDK。

## 3. 涉及網路的兩處

- 3.1. 關於頁面會向 GitHub 公開介面發出請求，讀取作者頭像與貢獻者名單。請求只會送往 api.github.com 與 avatars.githubusercontent.com，攜帶 GitHub 要求的標準 User-Agent，不攜帶任何裝置或使用者識別碼。GitHub 因此會看到你的 IP 位址。
- 3.2. 首次啟動精靈與設定頁面會從 GitHub 擷取使用者條款與隱私權政策的正文，使文本可以獨立於版本更新。請求同樣只攜帶標準標頭。若擷取失敗，將顯示安裝包內的副本或給出失敗提示。
- 3.3. 除此之外，本模組不會發起任何網路請求。

## 4. 與第三方共享

- 4.1. 我們不與任何第三方共享你的資訊，因為我們根本沒有收集。
- 4.2. 上述 GitHub 請求屬於你直接與 GitHub 互動，受 GitHub 自身的隱私權政策約束。
- 4.3. 當你主動匯出日誌並分享時，接收方由你選擇，此行不構成我們的共享行為。

## 5. 保留與刪除

- 5.1. 日誌依固定上限自動裁剪，超出後刪除最舊的記錄。
- 5.2. 你可以在應用程式內清空日誌，或直接刪除模組資料。
- 5.3. 解除安裝本模組會一併刪除其私有目錄中的全部資料。
- 5.4. 外部儲存中的日誌鏡像需要你在解除安裝前手動刪除。

## 6. 你的權利

- 6.1. 你可以隨時查看、匯出、清空本模組保存的全部資訊。
- 6.2. 你可以拒絕任何權限，對應功能將無法使用。
- 6.3. 你可以在設定中清除鎖定畫面密碼，檔案內容會被清空。

## 7. 未成年人

- 7.1. 本模組面向具備一定系統知識的使用者。未成年人應在監護人指導下使用。
- 7.2. 因為涉及 root 與腳本執行，我們不建議未成年人獨立操作。

## 8. 政策變更

- 8.1. 本政策可能隨版本更新修訂；修訂後的版本隨新建置發布，並公開於儲存庫。
- 8.2. 若某次修訂涉及新的資訊處理方式，我們會在更新說明中明確寫出。

## 9. 聯絡我們

- 9.1. 隱私相關問題請透過專案儲存庫的問題回報頁面反映。
- 9.2. 本模組的原始碼公開可稽核，你可以自行驗證上述說法。
